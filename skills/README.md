# Скиллы

Готовые agent-скиллы этого проекта. Их можно скопировать в свой агент — тогда он будет
создавать Markdown-файлы в том стиле, который редактор отображает правильно с первого раза.

## `markdown-diagrams` — обязательный стиль документов

Скилл требует, чтобы **каждый** создаваемый агентом `.md` содержал:

- минимум одну схему Mermaid (в документе длиннее ~150 строк — две и больше), тип схемы
  подбирается по содержанию раздела: `flowchart` для архитектуры, `sequenceDiagram` для
  взаимодействий, `stateDiagram-v2` для жизненных циклов, `erDiagram` для схем БД, `gantt` для
  планов, `mindmap` для карты темы, `pie` для долей;
- GFM-таблицы для сравнений и перечислений фактов;
- списки задач `- [ ]` для статусов, блоки кода с указанием языка, формулы KaTeX, сноски;
- один `# H1` на документ и ненулевую иерархию `##` / `###`.

Он же перечисляет типичные ошибки синтаксиса Mermaid — метки со спецсимволами без кавычек,
узел с именем `end`, неверное направление потока, — из-за которых схема не отрисуется.

**Зачем это здесь.** Редактор рендерит Mermaid, GFM и KaTeX, поэтому документ, написанный по
этому скиллу, сразу выглядит так, как задумано. Документ, написанный без него, обычно
представляет собой сплошной текст с редкими заголовками — читать его тяжело, а связи между
частями приходится восстанавливать в голове.

### Как установить

Скопировать каталог `markdown-diagrams` целиком — вместе с `references/`, на который ссылается
`SKILL.md`.

| Инструмент       | Куда положить                                                                    |
| ---------------- | -------------------------------------------------------------------------------- |
| Проектные скиллы | `<проект>/.agents/skills/markdown-diagrams/`                                     |
| Личные скиллы    | `~/.agents/skills/markdown-diagrams/` (Windows: `C:\Users\<вы>\.agents\skills\`) |
| Claude Code      | `<проект>/.claude/skills/markdown-diagrams/`                                     |

```bash
# Linux / macOS — личная установка
cp -r skills/markdown-diagrams ~/.agents/skills/

# Windows PowerShell — то же самое
Copy-Item -Recurse skills\markdown-diagrams "$env:USERPROFILE\.agents\skills\"
```

Если инструмент не поддерживает каталоги скиллов, содержимое `SKILL.md` можно вставить как
правило проекта или в системную инструкцию агента — файл самодостаточен.

### Как проверить

Откройте `skills/markdown-diagrams/references/exemplar.md` в редакторе: это образец документа в
требуемом стиле, и в нём видно, как выглядят все элементы — обзорная схема, схема состояний,
диаграмма последовательности, таблица контракта API, список задач, сноска и формула.

`SKILL.md` — хороший тест и для самого редактора: шаблон документа внутри него вложен в
четырёхбэктиковый блок, внутри которого лежат трёхбэктиковые блоки Mermaid.

# DaVinci Markdown Editor 0.4.0

Mermaid diagrams now draw **orthogonal, collision-free routes** instead of Mermaid's default curves.
On flowcharts and state machines the arrows leave a shape, turn at right angles and arrive at a
dedicated port, edge labels sit beside their own line instead of on top of a neighbour's, and the
back edge takes an outer corridor so a feedback loop no longer slices through the diagram.

## What's new

### Diagrams

- **Orthogonal routing for flowcharts and state diagrams.** Mermaid keeps computing the layout
  (node positions are unchanged); the routes are rebuilt from horizontal and vertical segments
  with right-angled turns. A port is never shared by two edges: two connections leaving the same
  side are displaced in the direction each edge is heading, so they cannot collapse into one line.
- **Diamond vertices are respected.** A decision node is entered through a free vertex
  (top/left/right/bottom) rather than through the middle of an edge, and a used vertex is never
  reused by a second connection.
- **Counter-edges get their own lanes.** A forward and a reverse transition between the same two
  states have separate ports, separate corridors and separate text zones; the back edge is routed
  outside the node cloud.
- **Self-loops are rectangular** and stay beside their state; the note connector is dotted, has no
  arrow head, and the note itself is moved to the right of its state (below the loop), as the
  reference layout asks.
- **Edge labels stay readable.** A label is measured, placed next to the longest segment of its own
  edge, and shifted along that segment if it would touch a foreign line, a shape or another label.
- **Diagram typography.** The first text row of a node is its title and is rendered semibold; edge
  labels stay regular; rectangles get a 4 px corner radius (diamonds and cylinders keep their own
  shape); edge strokes are 1.6 px. Text size stays 16 px. Author `classDef`/`style`/`linkStyle`
  still win over the theme, and colour/geometry rules never override a document's fills.
- **One font for measuring and drawing.** Mermaid measures label widths with the config font family
  and paints with the theme variable; both now come from the same constant, so labels are no longer
  sized against a different font than the one they are drawn in.
- **Safe fallback.** The router only touches `flowchart` and `stateDiagram` SVGs. An unknown diagram
  type, an unreadable structure or a missing DOM returns Mermaid's own SVG unchanged, and an edge
  whose route still collides keeps Mermaid's path rather than guessing.

### Under the hood

- `RENDER_VERSION` is now `render-4`, `LAYOUT_VERSION` is `layout-2` and `PALETTE_VERSION` is
  `davinci-2`, so a cached SVG from an earlier version can never be reused with the new geometry.
- Flowchart spacing is part of the cache key: `curve: "step"`, `nodeSpacing: 56`,
  `rankSpacing: 76`, `padding: 16`.
- The orthogonal router lives in `src/mermaid/route/` (pure geometry + a DOM pass) and runs after
  Mermaid renders, before the SVG is sanitised and cached.

## Verification

- `npm run verify`: typecheck, ESLint, Prettier, **361 frontend tests**, `cargo fmt`,
  `cargo clippy -D warnings`, 85 Rust tests — all exit 0.
- Both acceptance sources from `DaVinci_Mermaid_Render_TZ.md` were rendered in the in-repo Render
  Lab: the Goodland integration flowchart (7 shapes, 9 arrows of which 3 dotted) and the reservation
  state diagram (4 states, 8 transitions, 6 transition labels). An independent geometry check
  reports 0 slanted segments, 0 crossings, 0 shared segments, 0 routes through a shape and 0 label
  collisions in both light and dark themes.
- Exported SVGs are standalone (`xmlns`, `viewBox`, text, markers, dashes, no `foreignObject`) and
  open directly in a browser; screenshots for both diagrams in both themes are in
  `docs/screenshots/mermaid/`.
- Narrow-window check: at 600 px the diagram fits to 35% and nothing is clipped.
- No regressions in the other diagram types (sequence, class, ER, Gantt, Git graph, mindmap,
  timeline, pie) — each still renders as before.

## Known limitations

- The `extend` label of a self-loop stays where Mermaid placed it: the loop's own segment is 28 px
  wide and the label is 52 px, so it cannot sit on the loop without overlapping. It does not touch
  any other line or label.
- Routing is applied to flowchart and state diagrams only. Other diagram types keep Mermaid's
  geometry.
- A `classDef` fixed to the dark palette still keeps dark fills in the light theme — author
  styling outranks the theme by design.
- Installers are not code-signed; the first launch still shows the platform's own warning.

## Upgrade notes

Settings, sessions, recent files and file associations carry over from 0.3.0 unchanged. Existing
documents need no edits: the routing is a rendering change, and a document's own
`classDef`/`style`/`linkStyle` keeps priority.

# DaVinci Markdown Editor 0.3.0

Diagrams now render in the DaVinci palette, and the editor opens four more document formats:
JSON, CSV, LOG and XML. Every format has its own editor grammar, structured view, file icon and
operating-system association.

## What's new

### Diagrams

- **DaVinci palette.** Flowcharts, sequence, class, state, ER, Gantt, Git graph, mindmap, timeline
  and pie diagrams are rendered with a brand palette: action, condition, success, error and data
  roles each get a fill, a stroke and a shape, with text contrast of at least 4.5:1. An explicit
  `classDef`/`style` written in the document still wins.
- **Fit is the default, 100% is a separate button.** Zoom has one source — the SVG width and height —
  so scrolling always matches the drawing. Zoom range is 20–600%, and resizing the window re-fits
  only while the view is in fit mode. A diagram also opens fullscreen (an overlay, so it works in
  both WebView2 and WebKitGTK) and its Mermaid source can be copied in one click.
- **Two identical diagrams on one page both work.** Ids and local references (`url(#…)`, `href="#…"`,
  marker and clipPath definitions) are prefixed per instance, so arrows never point at the wrong
  diagram.
- **Exported SVG is self-contained**: colours, fonts, markers, `viewBox`, Cyrillic labels, no user
  zoom transform, no external references. Renders still go through one serialised initialize/render
  queue; a cancelled or late render never publishes its result.
- **No more clipped labels**: the viewBox is widened when Mermaid's geometry is smaller than the
  text around it.

### Document formats

| Format | Preview | Keeps exactly |
| --- | --- | --- |
| JSON | Tree with collapse, counts and value types, plus JSON Pointer copy | Number lexemes (`9007199254740993`), key order, escapes, duplicate keys |
| CSV | Virtualised table with record numbers, sort, filter and column resize | Quoting, multi-line cells, `;`/tab/pipe dialect, `000123` as a string |
| LOG | Event list with levels, filters, counters and collapsible stack traces | Event boundaries, physical line ranges, the time as written |
| XML | Tree with attributes, CDATA, comments, PIs and mixed content | Node order, namespaces, `xml:space` |

- **Source text stays the source of truth.** Viewers only derive a model. Sorting a CSV or filtering
  a log never changes the file; JSON _Format_/_Minify_ are explicit commands applied as one undo step.
- **Errors are local and navigable.** A parse error shows line:column, clicking it moves the caret to
  the source, and the rest of the document remains available.
- **Large files degrade honestly.** Above 2 MiB a viewer starts in the source with a _Build view_
  button; CSV renders only the rows in view; truncated models say so.

### Icons and OS integration

- Five generated brand icons (graphite document + DV mark, one colour and symbol per format):
  `.ico` with 16–256 px entries for Windows, PNGs from 16 to 512 px, and a native SVG set in the app.
- Explorer, tab bar and status bar show the format icon; the status bar names the format.
- The Windows installer registers one ProgID per format with its own `DefaultIcon` (NSIS hook), and
  uninstall removes them. Linux MIME registration covers all five formats; macOS declares the types
  in the bundle.

### Smaller improvements

- **New File** now offers Markdown, JSON, CSV, LOG, XML or plain text.
- **Save As** uses the current format's filter and keeps the extension; saving under another extension
  switches the viewer.
- Markdown-only commands (formatting, insert, diagram, export) are disabled for structured documents.
- The outline panel follows the document kind: headings, JSON/XML structure, CSV columns, LOG groups.
- Windows 1251 and the other encodings, EOL preservation, expected-hash conflict handling and
  session restore are unchanged and still apply to every format.

### What the Windows installer registers

- Five ProgIDs (`DaVinci.Markdown.Document`, `DaVinci.Json.Document`, `DaVinci.Csv.Document`,
  `DaVinci.Log.Document`, `DaVinci.Xml.Document`) covering 21 extensions.
- A per-format `DefaultIcon` under `%LOCALAPPDATA%\DaVinci Markdown Editor\icons\filetypes\`.
- A quoted `shell\open\command`, an `OpenWithProgids` entry for every extension (other
  applications' entries are preserved), and an application entry with capabilities so the app is
  listed in "Open with" and "Default apps".
- The previous default handler of each extension is kept in a backup and restored on uninstall,
  including across repeated upgrades of this application (the original is snapshotted once, not
  re-captured from our own earlier values).

## Known limitations

- Not code-signed (same as 0.2.2).
- Parser diagnostic messages are technical English; the surrounding UI is translated.
- LOG follow mode and XML `DOCTYPE`/external entity resolution are not implemented (by scope).
- The MSI associates formats with the application icon; the per-format icon override ships with the
  NSIS installer.
- A diagram `classDef` fixed to the dark palette keeps dark fills in the light theme — author styling
  outranks the theme by design.

## Upgrade notes

Settings, sessions and recent files carry over from 0.2.2. A settings file that already names a
Mermaid theme keeps it; the new DaVinci palette is the default only for new and reset settings.
